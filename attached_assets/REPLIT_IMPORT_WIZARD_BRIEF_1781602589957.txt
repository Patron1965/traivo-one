1. ÖVERSIKT
-----------------------------------------------------------------
En session-baserad, 3-stegs wizard för hierarkisk objektimport:

  Steg 1: Organisation  →  Steg 2: Butiker  →  Steg 3: Fysiska objekt

Varje steg:
  • Ladda upp Excel/CSV ELLER klistra in data
  • Mappa kolumner mot systemfält + metadatafält
  • Förhandsgranska matchning
  • Validera + Commit
  • INR → Systemnummer-mappning sparas i session

⚠️  VIKTIGT: INGET kundval! Objekt skapas oberoende av kund.
    Kundrelation hanteras senare i orderkonceptet.

7. INTERNUMMER-MAPPNING (INR)
-----------------------------------------------------------------

KONCEPT:
  Användaren tilldelar mänskligt läsbara, temporära nummer för att
  bygga hierarki. Systemet mappar dessa till systemnummer efter
  varje commit.

EXEMPEL-FLÖDE:

Steg 1 — Import:
  ┌────────┬───────────────────────┐
  │ INR    │ Namn                  │
  ├────────┼───────────────────────┤
  │ ORG-1  │ Axfood Huvudkontor    │
  │ ORG-2  │ Region Syd            │
  └────────┴───────────────────────┘

Steg 1 — Efter Commit:
  Session-mappning:
  {
    "ORG-1": 1001,
    "ORG-2": 1002
  }

Steg 2 — Import:
  ┌────────┬───────────────────────┬──────────┐
  │ INR    │ Namn                  │ Parent   │
  ├────────┼───────────────────────┼──────────┤
  │ BUT-1  │ Willys Malmö          │ ORG-2    │ ← Referens!
  │ BUT-2  │ Willys Lund           │ ORG-2    │
  └────────┴───────────────────────┴──────────┘

Steg 2 — Vid Commit:
  • Läs Parent "ORG-2"
  • Slå upp i mappning → 1002
  • Skapa objekt med ParentNr: 1002
  • Nytt systemnummer: 1010
  • Uppdatera mappning: "BUT-1": 1010

Steg 2 — Efter Commit:
  Session-mappning:
  {
    "ORG-1": 1001,
    "ORG-2": 1002,
    "BUT-1": 1010,
    "BUT-2": 1011
  }

Steg 3 — Import:
  ┌────────┬───────────────────────┬──────────┐
  │ INR    │ Namn                  │ Parent   │
  ├────────┼───────────────────────┼──────────┤
  │ OBJ-1  │ Kärltömning 240L      │ BUT-1    │ ← Referens Steg 2
  │ OBJ-2  │ Regional kärltömning  │ ORG-2    │ ← Referens Steg 1 (OK!)
  └────────┴───────────────────────┴──────────┘

Steg 3 — Vid Commit:
  • OBJ-1: Parent "BUT-1" → 1010 → ParentNr: 1010 ✅
  • OBJ-2: Parent "ORG-2" → 1002 → ParentNr: 1002 ✅

9. SESSION MANAGEMENT
-----------------------------------------------------------------

SESSION STATE:

interface WizardSession {
  sessionId: string;              // "18a022e0"
  createdAt: Date;
  status: "active" | "completed" | "aborted";
  currentStep: 1 | 2 | 3;
  
  // INR → Systemnummer mappning (växer för varje steg)
  inrMapping: Record<string, number>;
  
  // Resultat per steg
  step1Result?: {
    imported: number;
    timestamp: Date;
    objects: Array<{ inr: string; systemNr: number; name: string }>;
  };
  step2Result?: { ... };
  step3Result?: { ... };
}

SESSION LIFECYCLE:
  1. Start wizard → Skapa session (POST /api/import/wizard/start)
  2. Efter varje commit → Uppdatera session
  3. Efter steg 3 → Markera "completed"
  4. Timeout: 30 min inaktivitet → Auto-cleanup
  5. "Avbryt session" → Markera "aborted", rensa inte data (data finns kvar i DB)

STORAGE:
  • Redis (recommended): Fast, TTL-stöd
  • Database table: Mer persistent, kräver cleanup-job

15. TEKNISKA NOTES
-----------------------------------------------------------------

PARSING:
  • CSV: PapaParse (frontend) eller csv-parse (Node)
  • Excel: XLSX.js (SheetJS)
  • Läs första bladet, rad 1 = headers

VALIDERING:
  • Kör INNAN commit
  • Returnera alla fel på en gång (ej stoppa vid första)
  • Highlight felade rader i preview

TRANSACTION HANDLING:
  • Varje steg-commit i egen DB transaction
  • Om ett objekt misslyckas: Rollback hela steget
  • Tidigare steg påverkas EJ (de är redan committade)

CIRCULAR REFERENCE CHECK:
  Algorithm: DFS från varje objekt, följ parent-chain
  Om vi når samma objekt igen → cirkel

  function hasCircularReference(
    inr: string, 
    data: Row[], 
    visited: Set<string> = new Set()
  ): boolean {
    if (visited.has(inr)) return true;
    visited.add(inr);
    
    const row = data.find(r => r.inr === inr);
    if (!row || !row.parentINR) return false;
    
    return hasCircularReference(row.parentINR, data, visited);
  }
